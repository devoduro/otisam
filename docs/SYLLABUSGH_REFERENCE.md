# SyllabusGH: feature reference survey (app.syllabusgh.com)

Surveyed 2026-10-21 as a **feature reference only**, signed out. No questions, papers, notes or
reports were copied; WAEC past papers and Chief Examiner reports belong to WAEC.

## Structure

- **Home**: learning levels as big cards (Pre-school, Primary B1–6, JHS 1–3, SHS 1–3,
  TVET/STEM Form 1–3), a "Top scorer" leaderboard card (name + points), an "AI Tutor" box
  ("Solve homework" free-text question) and a floating "Magic Quiz" button.
- **Level page** (e.g. SHS): class selector (SHS 1/2/3), toggle *Syllabus* (old) vs *New
  Curriculum*, toggle *Core* vs *Elective*, then subject cards.
- **Subject hub** (e.g. SHS 1 Mathematics, Core): one screen of 12 tiles, everything for that
  subject in one place:
  New Curriculum · Past Questions · Learning Journey · Mock/Sample Questions · Sample Notes ·
  Take a Quiz · Practical Quiz · 1v1 Quiz Battle · Lesson Resources · Chief Examiners Report ·
  Video Lessons · Trending Questions
- **Sidebar**: Home, Trending, WOTD (word of the day), Tracker (study tracker), Settings, dark mode.

## What the tiles do (as seen)

| Tile | Behaviour |
|---|---|
| Past Questions | Grid of paper documents per year and paper (Paper 1, Paper 2, separate "Solution" documents, private-candidate papers), filter All / Objectives / Theory, "Load more". |
| Take a Quiz | Filter ALL / SHS 1 / SHS 2 / SHS 3; tabs Available quizzes · AI generator · Community quizzes; each quiz card shows progress (0/50). Quizzes include past-paper objectives and their own "Super Mock" series. |
| 1v1 Quiz Battle | "Battle arena": random match or private room (create / join with a code). |
| Chief Examiners Report | List of reports by year per subject. |
| Learning Journey | Step-by-step learning path; "coming soon" for Mathematics. |
| Trending (sidebar) | Community Q&A feed: learners post questions tagged by level, others comment. |
| Top scorer | Points from quizzes, shown as a leaderboard. |

Not opened: WOTD, Tracker, Settings, Magic Quiz, notes and resources tiles (sign-in or no
navigation while signed out).

## Otisam today vs SyllabusGH

| SyllabusGH | Otisam |
|---|---|
| Level → class → subject → hub of everything | Separate sections (Library, Practice, Videos, Downloads, Lesson plans, Subjects & topics); no single per-subject hub |
| New Curriculum tile | Subjects & topics (curriculum tree) |
| Past Questions (documents) | Library (exam papers with exam type, year, paper number, copyright/licence, takedowns) |
| Take a Quiz / Mock questions | Practice (filters, timed mode) + practice papers (in progress, uncommitted) |
| Video Lessons / Lesson Resources / Sample Notes | Video lessons, Downloads, Lesson plans |
| Chief Examiners Report | Could be a Library category; none yet |
| Points, top scorer, progress per quiz | Last 5 scores in the session only; no saved attempts |
| 1v1 Quiz Battle | None |
| Trending community Q&A | None |
| AI Tutor, AI quiz generator | None |
| Learning Journey, WOTD, study tracker | None |
